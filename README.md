# UnderStand Ionic

A small Android app built with **Ionic React** and **Capacitor** while learning Ionic. It has three tabs: a task manager whose tasks stay saved on the phone, a progress and settings screen, and a "Multiverse Explorer" that loads characters from the public Rick and Morty API.

## 📱 Download the APK

**[⬇️ Download understand-ionic.apk](https://github.com/ZaidReshamwale/UnderStandIonic/raw/develop/apk/understand-ionic.apk)** (debug build, ~5 MB)

The file is also in this repo at [`apk/understand-ionic.apk`](apk/understand-ionic.apk).

To install it on an Android phone (Android 7.0 / API 24 or newer):

1. Download the APK on the phone, or copy it over from your computer.
2. Open the file. If Android asks, allow your browser or file manager to **install unknown apps**.
3. Tap **Install**, then open **my-ionic-app**.

Or, with the phone connected over USB and USB debugging turned on:

```bash
adb install apk/understand-ionic.apk
```

> This is a debug build signed with the default debug key. It is fine for testing, but it cannot go on the Play Store.

## ✨ Features

### ✅ Tasks tab
- Add a task with a title and optional notes from a modal (the **+** button)
- Tick a checkbox to mark a task done (done tasks are struck through)
- Swipe a task left to delete it, with a confirmation alert
- Tap the arrow to open the **task detail** page and edit the title, notes and done state
- A counter of remaining tasks in the list header
- Toasts confirm each add and delete
- **Tasks are saved on the device** with `@capacitor/preferences`, so they are still there after you close the app

### ⚙️ Settings tab
- An animated **progress ring** showing what percentage of tasks are done, with a matching message
- Stat tiles for total, done and remaining tasks
- **Light / Dark / System** theme switch
- **Clear completed tasks**, with a confirmation alert
- App version and an "about" section

### 🪐 Explore tab (Multiverse Explorer)
- Loads characters from the [Rick and Morty API](https://rickandmortyapi.com) (no API key needed)
- **Search by name** (debounced so it does not call the API on every keystroke)
- Filter by status: **All / Alive / Dead / Unknown**
- **Infinite scroll** loads the next page as you reach the bottom
- **Pull to refresh**
- Skeleton cards while the first page loads, and screens for errors and empty results with a "Try again" button
- Tap a card to open a **bottom sheet** with the character's gender, origin, last location and episode count
- A **shuffle button** that opens a random character
- Cancels an old request when a newer search starts, so slow answers can't overwrite newer results

## 🚀 Run it locally

You need [Node.js](https://nodejs.org) 22 or newer. For the Android build you also need [Android Studio](https://developer.android.com/studio) with the Android SDK and JDK 21.

```bash
# Install dependencies
npm install

# Start the dev server in the browser (http://localhost:5173)
npm run dev
```

The Explore tab needs an internet connection because it calls the Rick and Morty API.

### Other scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Starts the Vite dev server |
| `npm run build` | Type-checks and builds the web app into `dist/` |
| `npm run preview` | Serves the built `dist/` folder |
| `npm run test.unit` | Runs unit tests with Vitest |
| `npm run test.e2e` | Runs Cypress end-to-end tests |
| `npm run lint` | Runs ESLint |

## 🤖 Build the Android APK yourself

```bash
# 1. Build the web app
npm run build

# 2. Copy the build and plugins into the Android project
npx cap sync android

# 3a. Build the debug APK from the command line
cd android && ./gradlew assembleDebug && cd ..

# 3b. ...or open the project in Android Studio and use Build > Build APK(s)
npx cap open android
```

The APK is written to `android/app/build/outputs/apk/debug/app-debug.apk`. To update the download link above, copy it over the old one:

```bash
cp android/app/build/outputs/apk/debug/app-debug.apk apk/understand-ionic.apk
```

To run straight on a connected phone or emulator, use `npx cap run android`.
